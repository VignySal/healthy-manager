# 冰箱清空大师 - 微信小程序 项目总结

## 项目概述

一款基于 **阿里云通义千问大模型** 的智能饮食管理微信小程序，核心功能包括：拍照识别食材、AI 生成菜谱、AI 识别食物卡路里、每日饮食摄入追踪与趋势分析。

- **AppID**: `wxa98a9e09de4ce07b`
- **基础库版本**: 3.15.0
- **云开发环境**: Tencent CloudBase (TCB)，环境 ID `cloud1-d4gplno2v8a70d862`
- **AI 服务**: 阿里云 DashScope API（qwen3.5-plus / qwen3.6-flash / qwen3-vl-plus）

---

| 层次 | 技术选型 |

## 页面功能

### 1. 健康首页 (`pages/health/health`) — Tab 首页
- 展示当月饮食日历，每天格子根据卡路里摄入量显示不同颜色
- 支持月份切换（上一月/下一月）
- 点击日期跳转至「饮食概览」查看当天详情
- 快捷入口：冰箱扫描（拍照识别食材）、手动选材、卡路里识别
- 从云端加载当月饮食记录并合并到日历

### 2. 冰箱扫描 (`pages/index/index`)
- 支持拍照/相册选择最多 6 张食材图片
- 调用阿里云 qwen3.5-plus 多模态模型批量识别图片中食材
- 每 2 张图片一组并行 API 调用，取所有结果并集
- 支持单图缓存（24 小时内相同图片不重复识别）
- 也提供直接跳转「手动选材」入口

### 3. 手动选材/识别结果 (`pages/recognize/recognize`)
- 展示识别出的食材列表，支持删除、手动输入添加
- 常用食材快捷添加（列表可从饮食偏好同步）
- 烹饪参数配置：
  - **烹饪风格**: 标准家常 / 减脂健康 / 儿童营养
  - **辣度**: 不吃辣 / 微辣 / 中辣 / 特辣 / 任意
  - **烹饪时间**: 15/30/45/60 分钟或自定义
  - **菜谱数量**: 1/2/3 道
  - **模式**: 推荐模式 / 聚餐模式（按人数 3-6 人定制菜单，含主菜、炒菜、凉菜、汤品分类）

### 4. AI 菜谱生成 (`pages/recipes/recipes`)
- 调用阿里云 qwen3.6-flash 生成详细菜谱（JSON 格式返回）
- 每条菜谱包含：菜名、难度、烹饪时间、卡路里、所需食材（区分已有/缺失）、详细步骤
- 聚餐模式按分类展示（主菜、炒菜、凉菜、汤品）
- 每道菜可添加到指定餐次（早餐/午餐/晚餐/加餐）→ 自动计入当日饮食记录
- 可收藏菜谱到「我的食谱」
- 菜谱保存时同步到云端

### 5. 饮食概览 (`pages/diet-overview/diet-overview`) — Tab 页
- 按日期查看当日四餐（早餐、午餐、晚餐、加餐）记录
- Canvas 2D 绘制环形进度条：绿色(0-100%)→橙色(100-120%)→红色(120%+)
- 支持日期切换（前一天/后一天/日期选择器）
- 支持编辑和删除记录（编辑弹窗含名称、总卡路里、分享人数、时间）
- 分享人数功能：总卡路里 ÷ 人数 = 人均摄入
- 数据自动同步到 CloudBase 数据库
- 入口：跳转卡路里识别页面

### 6. 摄入趋势 (`pages/calorie-trend/calorie-trend`) — Tab 页
- Canvas 2D 绘制折线图展示近 7/15/30 天卡路里摄入趋势
- 按餐次（早餐/午餐/晚餐/加餐/总计）分别展示，可单独开关
- 显示每日目标参考线（橙色虚线）
- 图表右上角图例，总计线突出显示，其他线半透明
- 计算并显示选定时间范围的平均摄入量

### 7. 个人中心 (`pages/profile/profile`) — Tab 页
- 微信登录/退出（wx.login + wx.getUserProfile）
- 登录后初始化云开发获取 openid
- 入口：我的食谱、饮食偏好
- 登录态通过 wx.Storage 持久化

### 8. 卡路里识别 (`pages/calorie/calorie`)
- 拍照/选图后调用阿里云 qwen3-vl-plus（降级 qwen3.5-plus）识别食物
- 返回：食物名称、卡路里、营养成分、健康建议
- 可添加到指定餐次的当日饮食记录
- 可收藏到「我的食谱」
- 支持选择日期（来自饮食概览页的日期传递）

### 9. 我的食谱 (`pages/my-recipes/my-recipes`)
- 展示收藏的菜谱和食物，支持展开查看详情
- 多种排序方式：最新/最早/按名称/按卡路里/手动排序
- 手动排序支持拖拽重排 + 保存
- 支持编辑收藏项（名称、卡路里、营养、烹饪时间、难度、图片等）
- 支持删除

### 10. 饮食偏好 (`pages/dietary-preferences/dietary-preferences`)
- **忌口食物**: 预设 + 自定义，AI 生成菜谱时作为硬约束
- **辣度偏好**: 5 级，会影响菜谱生成
- **口味偏好**: 清淡/酸甜/咸香/麻辣/酸辣
- **已有调料**: 预设 + 自定义，AI 优先使用已有调料
- **已有厨具**: 预设 + 自定义，AI 只推荐能用现有厨具做的菜
- **常用食材**: 预设 + 自定义，同步到手动选材页快捷列表
- **个人备注**: 自由文本，注入 AI prompt
- **每日卡路里目标**: 默认 1800 kcal，影响日历颜色和进度环
- 所有偏好自动保存（500ms 防抖），持久化到 wx.Storage

## 工具模块

### `utils/api.js` — AI API 调用
- 封装阿里云 DashScope Chat Completions API
- 请求重试（指数退避，最多 3 次），处理 429/5xx
- 图片压缩→Base64 编码→多模态识别
- JSON 提取解析（多种兜底策略：直接解析 → 正则提取 → 尾部截断重试）
- 卡路里文本解析（范围取中值 或 单数值提取）

### `utils/cloud.js` — 云端同步
- CloudBase 初始化（wx.cloud.init）
- 通过云函数 `getOpenid` 获取用户 openid
- 饮食记录 CRUD（diet_records 集合，按 openid 隔离）
- 批量日期范围查询（供日历使用）
- 待同步队列管理（网络离线时暂存，恢复后批量提交）

### `utils/constants.js` — 全局常量
- 每日卡路里目标（1800 kcal）
- API 重试配置、图片压缩质量
- 识别缓存 TTL（24 小时）
- 各 AI 模型参数配置

### `utils/util.js` — 通用工具
- 日期格式化、时间处理、Toast/Loading 封装
- 图片压缩、餐次名称映射

### `utils/logger.js` — 日志模块
- DEBUG 开关控制日志输出

## 数据流

```
用户拍照 → index(拍照页) → recognize(选材页)
  → API: qwen3.5-plus 多模态识别食材
  → API: qwen3.6-flash 生成菜谱
  → recipes(菜谱页) → 保存到餐次 → diet-overview(饮食概览)
  → StorageSync 本地存储 → CloudBase 云端同步
  → health(日历)/calorie-trend(趋势图) 读取展示
```
